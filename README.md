# 🔗 The Weakest Link | SETUP GUIDE

### 🚀 ЗАПУСК 
1. **Способ А (Самый простой):** 
   - Закинь папку `dist` на ноут.
   - Установи расширение "Web Server for Chrome" (если есть Chrome) или просто попробуй открыть `index.html`.
2. **Способ Б (Если есть Python):**
   - Зайди в `dist` через терминал (PowerShell/CMD).
   - Введи: `python -m http.server 8080`.
   - Открой в браузере: `localhost:8080`.
